# Hello World Chinese 你好世界

A beautiful and interactive Hello World webpage in Chinese with modern design principles.

## Features

- 🎨 **Modern Design**: Beautiful gradient backgrounds with glassmorphism effects
- ✨ **Animations**: Smooth fade-in animations, glowing text effects, and floating elements
- 🖱️ **Interactive**: Click buttons for greetings and background changes
- ⌨️ **Keyboard Support**: Press Enter for greetings, Space for background changes
- 📱 **Responsive**: Perfect adaptation for mobile, tablet, and desktop devices
- 🌟 **Pure HTML/CSS/JS**: No frameworks required, fast loading

## Live Demo

Visit the live website: [Hello World Chinese](https://yuzhang9804.github.io/hello-world-chinese/)

## Local Development

```bash
# Clone the repository
git clone https://github.com/yuzhang9804/hello-world-chinese.git

# Navigate to the project directory
cd hello-world-chinese

# Start a local server
python3 -m http.server 8000

# Open http://localhost:8000 in your browser
```

## Technologies Used

- HTML5
- CSS3 (with modern features like backdrop-filter, CSS Grid, Flexbox)
- Vanilla JavaScript
- Responsive Design
- Chinese Typography Optimization
